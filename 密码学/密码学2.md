## 密码学2

### 现代密码学

#### 消息认证码

- 消息完整性
  - 问题：加密方案不提供消息完整性
    - 一次性密码本、PRG加密、PRF加密、CTR模式等，敌手都可以通过翻转密文比特来对应翻转明文比特，且不会被检测到
  - 目标：防止消息被未授权篡改、防止未授权注入消息
- 消息认证码（MAC）
  - 定义：消息认证码 $\Pi = (\text{Gen}, \text{Mac}, \text{Vrfy})$ 包含三个PPT算法
    - $\text{Gen}(1^n)$：密钥生成，输出密钥 $k$，$|k| \geq n$
    - $\text{Mac}(k,m)$：标签生成，输入消息 $m$，输出标签 $t$
    - $\text{Vrfy}(k,m,t)$：验证，输出0或1
    - 正确性：$\text{Vrfy}(k,m,\text{Mac}(k,m)) = 1$
- CMA-安全
  - 消息认证实验 $\text{Mac-forge}_{\mathcal{A},\Pi}(n)$
    - 挑战者生成密钥 $k \leftarrow \text{Gen}(1^n)$
    - 敌手可以多项式次访问 $\text{Mac}(k,\cdot)$ 预言机，查询任意消息的标签
    - 敌手输出 $(m,t)$，实验输出1当且仅当：
      - $\text{Vrfy}(k,m,t) = 1$
      - $m$ 不在敌手之前查询过的消息集合 $Q$ 中
  - 定义：称$\Pi$在自适应选择消息攻击下不可伪造，如果对所有PPT敌手 $\mathcal{A}$，存在可忽略函数 $negl(\cdot)$，使得
    $$\Pr[\text{Mac-forge}_{\mathcal{A},\Pi}(n)=1] \leq negl(n)$$
  - 对应私钥加密的CPA-安全  
  - 重放攻击：敌手可以截获消息标签对 $(m,t)$ 并再次发送该组数据
    - 序列号：通信双方同步维护序列号计数器
    - 时间戳：发送 $T \| m$ 替代 $m$
    - 一次性随机数nonce
- 基于伪随机函数的固定长度消息认证码
  - 构造：给定PRF $F$，构造MAC方案 $\Pi = (\text{Gen}, \text{Mac}, \text{Vrfy})$
    - $\text{Gen}(1^n)$：随机选择 $k \leftarrow \{0,1\}^n$
    - $\text{Mac}(k,m)$：对 $m \in \{0,1\}^n$，输出标签 $t=F_k(m)$
    - $\text{Vrfy}(k,m,t)$：当且仅当 $t=F_k(m)$ 时输出1
  - 如果 $F$ 是PRF，则该MAC方案是CMA安全的
    - 实验：MAC自适应选择消息攻击实验
      - 三方角色
        1. $\mathcal{O}$：预言机，要么是MAC标签生成函数$Mac(k,\cdot)$，要么是理想随机函数$f(\cdot)$
        2. $\mathcal{D}$：PPT归约区分器，模拟MAC安全实验挑战者
        3. $\mathcal{A}$：MAC多项式时间CMA敌手
      - 阶段1：敌手多次查询标签预言
        1. $\mathcal{A}$依次发送多条消息$m_i,\ i\in[q]$给$\mathcal{D}$
        2. $\mathcal{D}$将$m_i$转发给预言机$\mathcal{O}$，获取标签$t_i=\mathcal{O}(m_i)$
        3. $\mathcal{D}$把$t_i$返回给敌手$\mathcal{A}$
      - 阶段2：敌手输出伪造消息标签对
        1. $\mathcal{A}$输出伪造对$(m,t)$发送给$\mathcal{D}$
        2. $\mathcal{D}$将伪造消息$m$发送给预言机$\mathcal{O}$，得到标准标签$t'=\mathcal{O}(m)$
      - 阶段3：区分器输出判定比特
        1. $\mathcal{D}$输出1当且仅当同时满足两个条件：
             - $m$从未在阶段1被敌手查询过：$m \notin \{m_i\}$
             - 敌手伪造标签与标准标签相等：$t = t'$  
    - 构造中间方案 $\Pi'$，用真随机函数 $f$ 替换PRF $F_k$
    - 第一步：证明 $|\Pr[\text{Mac-forge}_{\mathcal{A},\Pi}(n)=1] - \Pr[\text{Mac-forge}_{\mathcal{A},\Pi'}(n)=1]|$ 是可忽略的，否则存在区分器可以区分PRF和真随机函数
    - 第二步：证明 $\Pr[\text{Mac-forge}_{\mathcal{A},\Pi'}(n)=1] \leq 2^{-n}$ 是可忽略的
      - 敌手查询 $q$ 个消息后，伪造的新消息 $m$ 不在查询集合中，$f(m)$ 对敌手是真随机的，猜对概率为 $2^{-n}$
- 任意长度消息认证码
  - 朴素构造
    - 方案1：仅对每个分组单独生成标签
      - 构造：$m = m_1 \cdots m_d;\ t_i = \text{Mac}(k,m_i),\ t = t_1 t_2 \cdots t_d$
      - 攻击：分组重排序攻击（Block re-Ordering Attack）
        - 伪造消息标签对：$(m_3 m_2 m_1,\ t_3 t_2 t_1)$
    - 方案2：分组拼接序号再生成标签
      - 构造：$m = m_1 \cdots m_d;\ t_i = \text{Mac}(k,i\|m_i),\ t = t_1 t_2 \cdots t_d$
      - 攻击：截断攻击（Truncation attack）
        - 伪造消息标签对：$(m_1 m_2,\ t_1 t_2)$，丢弃末尾分组$m_d$
    - 方案3：分组拼接总长度+序号再生成标签
      - 构造：$m = m_1 \cdots m_d;\ t_i = \text{Mac}(k,l\|i\|m_i),\ t = t_1 t_2 \cdots t_d$
      - 攻击：混合匹配攻击（Mix-and-match attack）
        - 已知合法对：$(m_1 m_2 m_3,\ t_1 t_2 t_3),\ (m_1' m_2' m_3',\ t_1' t_2' t_3')$
        - 伪造消息标签对：$(m_1 m_2 m_3',\ t_1 t_2 t_3')$
  - 安全构造：$\Pi' = (\text{Gen}', \text{Mac}', \text{Vrfy}')$
    - 基础：$\Pi$ 是CMA安全的固定长度MAC
    - $\text{Gen}'(1^n)$：选择 $k \leftarrow \text{Gen}(1^n)$
    - $\text{Mac}'(k,m)$：$|m|=l<2^{n/4}$，随机选择 $r \leftarrow \{0,1\}^{n/4}$，将 $m$ 分块为 $m_1,\dots,m_d$，每块 $t_i=\text{Mac}(k,r||l||i||m_i)$，输出 $t=(r,t_1,\dots,t_d)$
    - $\text{Vrfy}'(k,m,t)$：$t=(r,t_1,\dots,t_{d'})$，$m=(m_1,\dots,m_d)$，当且仅当 $d'=d$ 且对所有 $i \in [d]$，$\text{Vrfy}(k,r||l||i||m_i,t_i)=1$ 时输出1
  - 定理：如果 $\Pi$ 是CMA安全的，则 $\Pi'$ 也是CMA安全的
  - CBC-MAC
    - 构造1：前置消息长度
      - 消息 $m=m_1\cdots m_d$，$t_0=F_k(|m|)$
      - 对 $i=1$ 到 $d$：$t_i=F_k(t_{i-1} \oplus m_i)$
      - 输出标签 $t=t_d$
    - 构造2：双密钥CBC-MAC
      - 选择 $k_1,k_2 \leftarrow \{0,1\}^n$
      - $t_0=0^n$，对 $i=1$ 到 $d$：$t_i=F_{k_1}(t_{i-1} \oplus m_i)$
      - 输出标签 $t=F_{k_2}(t_d)$
- 强存在不可伪造性（strongly existentially unforgeable under an adaptive chosen-message attack，sEUF-CMA）
  - 强伪造实验 $\text{Mac-sforge}_{\mathcal{A},\Pi}(n)$
    - 挑战者生成密钥 $k \leftarrow \text{Gen}(1^n)$
    - 敌手可以多项式次访问 $\text{Mac}(k,\cdot)$ 预言机
    - 敌手输出 $(m,t)$，实验输出1当且仅当：
      - $\text{Vrfy}(k,m,t)=1$
      - $(m,t) \notin Q$（$Q$ 是敌手查询过的所有消息标签对集合）
  - 定义：MAC是sCMA-安全的，如果对所有PPT敌手 $\mathcal{A}$，存在可忽略函数 $negl(\cdot)$，使得
    $$\Pr[\text{Mac-sforge}_{\mathcal{A},\Pi}(n)=1] \leq negl(n)$$
  - 安全关系：sCMA-安全蕴含CMA-安全
- 选择密文攻击安全（CCA-安全）
  - CCA不可区分实验 $\text{PrivK}_{\mathcal{A},\Pi}^{cca}(n)$
    - 挑战者生成密钥 $k \leftarrow \text{Gen}(1^n)$
    - 敌手可以多项式次访问加密预言机 $\text{Enc}(k,\cdot)$ 和解密预言机 $\text{Dec}(k,\cdot)$
    - 敌手输出两个等长明文 $m_0,m_1$
    - 挑战者随机选择 $b \leftarrow \{0,1\}$，返回挑战密文 $c \leftarrow \text{Enc}(k,m_b)$
    - 敌手可以继续访问预言机，但**不能用挑战密文 $c$ 查询解密预言机**
    - 敌手输出猜测 $b'$，实验输出1当且仅当 $b'=b$
  - 定义：加密方案是CCA-安全的，如果对所有PPT敌手 $\mathcal{A}$，存在可忽略函数 $negl(\cdot)$，使得
    $$\Pr\left[\text{PrivK}_{\mathcal{A},\Pi}^{cca}(n)=1\right] \leq \frac{1}{2} + negl(n)$$
  - 安全关系：CCA-安全蕴含CPA-安全
  - 已有方案的CCA不安全攻击
    - OTP、EAV-安全的PRG加密、CPA-安全的PRF加密、CPA-安全的CTR模式等，都可以通过修改密文比特后查询解密预言机来区分挑战明文
- 先加密后认证的CCA安全构造
  - 构造：$\Pi' = (\text{Gen}', \text{Enc}', \text{Dec}')$
    - $\Pi_E$ 是CPA-安全加密方案，$\Pi_M$ 是sCMA-安全的MAC
    - $\text{Gen}'(1^n)$：生成 $k_E \leftarrow \text{Gen}_E(1^n)$，$k_M \leftarrow \text{Gen}_M(1^n)$，输出 $k=(k_E,k_M)$
    - $\text{Enc}'(k,m)$：计算 $c \leftarrow \text{Enc}(k_E,m)$，$t=\text{Mac}(k_M,c)$，输出 $(c,t)$
    - $\text{Dec}'(k,(c,t))$：如果 $\text{Vrfy}(k_M,c,t)=0$ 输出 $\perp$，否则输出 $m=\text{Dec}(k_E,c)$
  - 定理：如果 $\Pi_E$ 是CPA安全的，$\Pi_M$ 是sCMA安全的，则 $\Pi'$ 是CCA安全的
    - MAC满足sCMA安全 ⇒ 解密预言$\text{Dec}'(k,\cdot)$无攻击利用价值
    - 移除解密预言机$\text{Dec}'(k,\cdot)$后，CCA安全实验退化为CPA安全实验

#### 哈希函数

- 密码学哈希函数定义
  - 哈希函数是一对PPT算法 $\Pi=(\text{Gen},H)$
  - $\text{Gen}(1^n)$：生成密钥/公开参数 $s$，$s$ 是公开的，不是私钥
  - $H^s:\{0,1\}^* \to \{0,1\}^{l(n)}$，定义域通常有限
  - 输入长度 $l'(n) > l(n)$
  - 固定输入长度的哈希函数称为压缩函数，
- 抗碰撞性Collision Resistance
  - 碰撞寻找实验 $\text{Hash-coll}_{\mathcal{A},\Pi}(n)$
    - 挑战者运行 $s \leftarrow \text{Gen}(1^n)$，将 $s$ 发送给敌手 $\mathcal{A}$
    - 敌手输出 $x,x' \in \text{Dom}(H^s)$
    - 实验输出1当且仅当 $x \neq x'$ 且 $H^s(x)=H^s(x')$
  - 定义：$\Pi$ 是抗碰撞的，如果对所有PPT敌手 $\mathcal{A}$，存在可忽略函数 $negl(\cdot)$，使得
    $$\Pr[\text{Hash-coll}_{\mathcal{A},\Pi}(n)=1] \leq negl(n)$$
  - 实际使用的密码学哈希函数
    - 无密钥，输出长度固定（$l = 160, 256, 512$），定义域有限
    - 无安全参数，无渐进行为，根据生日悖论进行安全性判断
- 第二原像抗性Second-Preimage Resistance
  - 第二原像寻找实验 $\text{Hash-SecPre}_{\mathcal{A},\Pi}(n)$
    - 挑战者运行 $s \leftarrow \text{Gen}(1^n)$，随机选择 $x \leftarrow \text{Dom}(H^s)$，将 $s,x$ 发送给敌手 $\mathcal{A}$
    - 敌手输出 $x' \in \text{Dom}(H^s)$
    - 实验输出1当且仅当 $x \neq x'$ 且 $H^s(x)=H^s(x')$
  - 定义：$\Pi$ 是第二原像抗性的，如果对所有PPT敌手 $\mathcal{A}$，存在可忽略函数 $negl(\cdot)$，使得
    $$\Pr[\text{Hash-SecPre}_{\mathcal{A},\Pi}(n)=1] \leq negl(n)$$
- 原像抗性Preimage Resistance
  - 原像寻找实验 $\text{Hash-Pre}_{\mathcal{A},\Pi}(n)$
    - 挑战者运行 $s \leftarrow \text{Gen}(1^n)$，随机选择 $x \leftarrow \text{Dom}(H^s)$，计算 $y=H^s(x)$，将 $s,y$ 发送给敌手 $\mathcal{A}$
    - 敌手输出 $x' \in \text{Dom}(H^s)$
    - 实验输出1当且仅当 $H^s(x')=y$
  - 定义：$\Pi$ 是原像抗性的，如果对所有PPT敌手 $\mathcal{A}$，存在可忽略函数 $negl(\cdot)$，使得
    $$\Pr[\text{Hash-Pre}_{\mathcal{A},\Pi}(n)=1] \leq negl(n)$$
- 安全等级蕴含关系
  - 抗碰撞性 ⇒ 第二原像抗性
    - 归约：假设敌手 $\mathcal{A}$ 能攻破第二原像抗性，构造PPT算法 $\mathcal{B}$ 攻破抗碰撞性
    - $\mathcal{B}$ 随机选择 $x \leftarrow \text{Dom}(H^s)$，调用 $\mathcal{A}(s,x)$ 得到 $x'$，输出 $(x,x')$
  - 第二原像抗性 ⇒ 原像抗性
    - 归约：假设敌手 $\mathcal{A}$ 能攻破原像抗性，构造PPT算法 $\mathcal{B}$ 攻破第二原像抗性
    - $\mathcal{B}$ 随机选择 $x \leftarrow \text{Dom}(H^s)$，调用 $\mathcal{A}(s,H^s(x))$ 得到 $x'$，输出 $x'$
- Davies-Meyer压缩函数构造
  - $F:\{0,1\}^n \times \{0,1\}^\ell \to \{0,1\}^\ell$ 是分组密码
  - 压缩函数 $h:\{0,1\}^{n+\ell} \to \{0,1\}^\ell$，定义为 $h(k,x)=F_k(x) \oplus x$
  - 定理：Davies-Meyer构造在理想密码模型下是抗碰撞哈希函数CRHF
  - 理想密码模型：所有参与方可以访问随机带密钥置换预言机 $F$ 和逆置换预言机 $F^{-1}$，只能通过向预言机输入$(k,x)$计算 $F(k,x)$ 或 $F^{-1}(k,x)$
- Merkle-Damgård变换
  - 将固定长度压缩函数扩展为任意长度哈希函数
  - $\Pi = (\text{Gen}', H)$ 为任意长度哈希函数
    - 基础：$\Gamma=(\text{Gen},h)$ 是输入长度 $2n$、输出长度 $n$ 的固定长度哈希函数
    - $\text{Gen}'(1^n)$：运行 $s \leftarrow \text{Gen}(1^n)$
    - $H^s(x)$：$x \in \{0,1\}^*$，$|x|=L<2^n$
      - $B=\lceil \frac{L}{n} \rceil$，将 $x$ 补0，分块为 $x_1\cdots x_B$，每块长度 $n$
      - $x_{B+1}=L$的$n$比特二进制表示
      - $z_0=0^n$，该初始值可以任意选取，只需保持固定不变即可。
      - 对 $i=1$ 到 $B+1$：$z_i = h^s(z_{i-1} \| x_i)$
        - $z_i = h^s(z_{i-1} \| x_i) = F_{x_i}(z_{i-1}) \oplus z_{i-1}$
      - 输出 $z_{B+1}$
  - Ex：MD5、SHA系列
  - 定理：如果 $\Gamma$ 是抗碰撞的，则 $\Pi$ 也是抗碰撞的
    - 实验：
      - 三方角色
        1. $\mathcal{O}$：预言机，可为分组密码相关置换、逆置换
        2. $\mathcal{B}$：PPT归约算法
        3. $\mathcal{A}$：攻破Merkle-Damgård哈希函数的PPT敌手
      - 阶段1：参数分发
        1. 挑战者运行 $s \leftarrow \text{Gen}(1^n)$，将公开参数 $s$ 发送给归约算法 $\mathcal{B}$
        2. $\mathcal{B}$ 直接将参数 $s$ 转发给敌手 $\mathcal{A}$
      - 阶段2：敌手输出哈希碰撞
        1. 敌手 $\mathcal{A}$ 输出长消息碰撞对 $(x,x')$，满足 $x\neq x'$ 且 $H^s(x)=H^s(x')$，并发送给 $\mathcal{B}$
      - 阶段3：归约算法提取压缩函数碰撞
        1. $\mathcal{B}$ 对 $x,x'$ 分别执行分块、填充，完整计算两组Merkle-Damgård迭代状态链
        2. 从最终迭代结果向前回溯，找到满足 $y\neq y'$ 且 $h^s(y)=h^s(y')$ 的输入对 $(y,y')$
      - 阶段4：提交结果完成归约
        1. $\mathcal{B}$ 将压缩函数的碰撞对 $(y,y')$ 提交给挑战者
        2. 挑战者判定实验结果，以此证明：若 $\mathcal{A}$ 能攻破外层哈希函数，则 $\mathcal{B}$ 可攻破底层压缩函数
    - 假设存在PPT敌手 $\mathcal{A}$ 以不可忽略概率 $\epsilon$ 找到 $H^s$ 的碰撞 $(x,x')$
    - 构造PPT算法 $\mathcal{B}$，调用 $\mathcal{A}$ 得到碰撞 $(x,x')$
    - 设 $x$ 分块为 $x_1\cdots x_B x_{B+1}$，$x'$ 分块为 $x'_1\cdots x'_{B'} x'_{B'+1}$
    - 因为 $H^s(x)=H^s(x')$，所以 $h^s(z_B \| x_{B+1})=h^s(z'_{B'} \| x'_{B'+1})$
    - 若 $z_B \| x_{B+1} \neq z'_{B'} \| x'_{B'+1}$，则 $(z_B \| x_{B+1}, z'_{B'} \| x'_{B'+1})$ 是压缩函数的碰撞
    - 否则 $x_{B+1}=x'_{B'+1}$，$B=B'$，$z_B=z'_B$，继续向前回溯，必然存在某一轮 $i$ 使得 $z_{i-1} \| x_i \neq z'_{i-1} \| x'_i$ 且 $h^s(z_{i-1} \| x_i)=h^s(z'_{i-1} \| x'_i)$，即为压缩函数的碰撞
    - 因此 $\Pr[\text{Hash-coll}_{\mathcal{B},\Gamma}(n)=1] \geq \epsilon$，与 $\Gamma$ 抗碰撞矛盾
- Hash-and-MAC
  - 针对任意长度消息认证码，主要研究了两类构造方案
    - 基于伪随机函数构造MAC：标签长度较长；需要执行大量伪随机函数运算
    - CBC-MAC构造：标签长度短，曾作为工业标准；但串行运算，运算速度不足
  - Hash-and-MAC构造任意长度消息认证码
    - 基础：$\Pi$ 是 $l(n)$ 比特固定长度CMA安全MAC，$\Pi_H$ 是输出长度 $l(n)$ 的哈希函数
    - $\text{Gen}'(1^n)$：选择 $k \leftarrow \text{Gen}(1^n)$，$s \leftarrow \text{Gen}_H(1^n)$，输出 $k'=(k,s)$
    - $\text{Mac}'(k',m)$：输出 $t=\text{Mac}(k,H^s(m))$
    - $\text{Vrfy}'(k',m,t)$：当且仅当 $\text{Vrfy}(k,H^s(m),t)=1$ 时输出1
  - 定理：如果 $\Pi$ 是CMA安全的，$\Pi_H$ 是抗碰撞的，则 $\Pi'$ 是CMA安全的
- HMAC
  - 将MAC嵌入哈希函数构造过程中
  - $\Pi=(\text{Gen}_{\Pi},\text{Mac},\text{Vrfy})$
  - 底层依赖工具
    - $(\text{Gen}',H)$，$(\text{Gen},h)$的Merkle-Damgård变换，$h$ 将 $n'+n$ 比特输入压缩为 $n$ 比特输出，一系列k与y为n比特，一系列xi与y'为n'比特
  - 固定常量参数
    - $\text{ipad}=3636\cdots36$，$\text{opad}=5\text{C}5\text{C}\cdots5\text{C}$，二者均为512比特固定常数
  - Mac标签生成完整流程
    - 内层哈希计算
      1. 密钥 $k$ 与 $\text{ipad}$ 做按位异或得到 $k\oplus\text{ipad}$
      2. 将 $k\oplus\text{ipad}$ 与原始消息 $m$ 拼接，输入哈希函数 $H^s$
         - $k_{in} = k_0 = h^s(IV \| k\oplus\text{ipad}) = F_{IV}(k\oplus\text{ipad}) \oplus (k\oplus\text{ipad})$
         - 后续过程, $k_i = h^s(k_{i-1} \| x_i) = F_{x_i}(k_{i-1}) \oplus k_{i-1}$ 
      3. 输出内层哈希结果 $y = H^s\left(\left(k\oplus\text{ipad}\right)\|m\right)$
    - 外层哈希计算
      1. 密钥 $k$ 与 $\text{opad}$ 做按位异或得到 $k\oplus\text{opad}$
      2. $y' = y \parallel \underbrace{0\cdots0}_{\text{填充0}} \parallel \underbrace{|y|}_{l\text{-bit 长度字段}}$
      3. 将 $k\oplus\text{opad}$ 与 $y$ 拼接，输入哈希函数 $H^s$，得到最终标签
          - $k_{out} = h^s(IV \| k\oplus\text{opad}) = F_{IV}(k\oplus\text{opad}) \oplus (k\oplus\text{opad})$
          - $t = h^s(k_{out} \| y') = F_{y'}(k_{out}) \oplus k_{out}$
    - $t = H^s\left(k\oplus\text{opad} \parallel H^s\left(\left(k\oplus\text{ipad}\right)\parallel m\right)\right)$
  - $x$ 与 $y$ 的填充规则
    - 约束条件：
      - 消息长度 $<2^l$ 比特，否则消息长度用$l$比特长度无法完整表示
      - 满足 $n+l \le n'$，否则$y'$需要经过两次$h^s$
    - 向x末尾追加足量0比特，再追加 $l$ 比特二进制形式的原始消息长度，使得「消息原始长度+填充0比特数量+$l$」是 $n'$ 的整数倍
    - 填充后消息结构：原始消息 || 填充0比特 || $l$比特原始消息长度二进制表示
    - 对于 $x$ ，按照$n'$拆分填充后消息
- 哈希函数攻击
  - 核心问题
    - 设 \(H:\{0,1\}^{*} \to \{0,1\}^{l}\) 是一个输出固定长度摘要的哈希函数，如何通过一般方法找到该哈希函数的碰撞
    - 碰撞定义：找到两个不同的消息 \(x_1 \neq x_2\)，使得 \(H(x_1)=H(x_2)\)，即两个不同输入得到相同哈希输出
  - 暴力碰撞攻击（平凡攻击）
    - 攻击流程
      - 均匀随机选取 \(q\) 个互不相同的消息 \(x_1, x_2, ..., x_q\)
      - 对每个消息计算哈希值 \(y_i = H(x_i)\)
      - 遍历所有哈希值，找到 \(i \neq j\) 且 \(y_i=y_j\)，输出碰撞对 \((x_i, x_j)\)
    - 攻击参数与性质
      - 选取消息数量：\(q = 2^l + 1\)（哈希输出共 \(2^l\) 种可能，根据鸽巢原理，选 \(2^l+1\) 个消息必然存在碰撞）
      - 攻击成功率：100%
      - 计算复杂度：\(O(2^l)\) 次哈希运算
      - 缺陷：对于128位哈希，需要计算 \(2^{128}\) 次，完全不可行
  - 生日攻击（碰撞攻击最优通用方法）
    - 攻击核心思想
      - 利用概率论中的生日悖论，不需要遍历所有可能的哈希值，仅需 \(O(2^{l/2})\) 次计算就能以50%概率找到碰撞，复杂度比暴力攻击低一个平方根量级
    - 攻击流程
      - 均匀随机选取 \(q\) 个互不相同的消息
      - 计算每个消息的哈希值
      - 若存在两个不同消息哈希值相同，输出碰撞对
    - 概率推导与证明
      - 简化假设
        - 将哈希函数视为真随机函数，即每个哈希值 \(y_1,...,y_q\) 独立均匀分布在 \(N=2^l\) 种可能结果中
      - 符号定义
        - \(Coll(q,N)\)：从 \(N\) 个结果中独立随机选 \(q\) 个值，出现至少一次重复的概率
        - \(C_{i,j}\)：事件「第i个和第j个哈希值相等」（\(i \neq j\)）
        - 总碰撞事件：\(C = \bigcup_{i \neq j} C_{i,j}\)
      - 无碰撞概率计算
        - 所有哈希值都不重复的概率 = 第一个值任意 × 第二个值不等于第一个 × 第三个值不等于前两个 × ... × 第q个值不等于前q-1个
        - 公式：\(Pr[\overline{C}]=\frac{N(N-1) \cdots(N-q+1)}{N^{q}}=\prod_{i=1}^{q-1}\left(1-\frac{i}{N}\right)\)
      - 经典生日问题验证
        - 生日问题：一个房间里至少需要多少人，才能保证存在两人生日相同的概率≥50%
        - 总可能生日数 \(N=365\)，计算得最小人数 q=23
      - 两个核心概率界
        - 引理1（碰撞概率上界）
          - \(Coll(q, N) \leq \frac{q(q-1)}{2 N}\)
          - 证明：碰撞概率 ≤ 所有两两对的碰撞概率之和（并集的概率≤各事件概率和，即容斥原理上界）
          - 总共有 \(\binom{q}{2} = \frac{q(q-1)}{2}\) 个两两对，每对碰撞概率为 \(1/N\)，因此总概率不超过 \(\frac{q(q-1)}{2N}\)
        - 引理2（碰撞概率下界）
          - 若 \(q ≤\sqrt{2 N}\)，则 \(Coll(q, N)≥1 - e^{-\frac{q(q-1)}{2N}} ≥ \frac{q(q-1)}{4N}\)
          - 证明：
            - \(Coll(q, N) = 1 - Pr[\overline{C}]\)
            - \(Pr[\overline{C}] = \frac{N(N-1)\cdots(N-q+1)}{N^q} = \prod_{i=1}^{q-1} \left(1 - \frac{i}{N}\right)\)
            - 对所有\(i \in [q-1]\)，不等式\(1 - \frac{i}{N} \leq e^{-\frac{i}{N}}\)成立
            - 因此\(Pr[\overline{C}] \leq e^{-\frac{q(q-1)}{2N}}\)
            - 代入得\(Coll(q, N) \geq 1 - e^{-\frac{q(q-1)}{2N}}\)
            - 进一步推导得下界\(Coll(q, N) \geq \frac{q(q-1)}{4N}\)
          - $q$ 可以略大于 $\sqrt{2N}$，如$q = \sqrt{2N} + 1$，$x = 1 + \frac{1}{\sqrt{2N}}$ ，当$N \geq 2$ 时，$e^{-x} < 1 - \frac{x}{2}$，同样有\(1 - e^{-\frac{q(q-1)}{2N}} \geq \frac{q(q-1)}{4N}\)
    - 生日攻击安全参数
      - 50%碰撞概率所需样本量：\(q = \sqrt{2N} + 1\)（N≥2时成立）
      - 哈希函数对应参数：哈希输出长度为$l$位时，\(N=2^l\)，因此需要 \(q ≈ 2^{l/2}\) 次计算
      - 安全设计要求
        - 若攻击者最多能做 \(T\) 次哈希计算，要求 \(\sqrt{2} \cdot 2^{l/2} + 1 > T\)，即 \(l > 2\log_2 T\)
        - n位安全：若攻击者能做 \(2^n\) 次计算，哈希输出长度至少需要 \(l≥2n\)
        - 例：80位安全需要160位哈希输出，128位安全需要256位哈希输出
      - 该条件是必要非充分，仅能抵抗生日攻击，不能保证哈希函数无其他结构漏洞

- Feistel网络
  - 核心优势
    - 不需要轮函数可逆，就能保证整个分组密码是可逆的（解密和加密使用几乎相同的结构），大幅降低设计难度
  - 单轮变换规则
    - 第i轮变换：输入上一轮的左右两半 \((L_{i-1}, R_{i-1})\)
    - 新左半部分 = 上一轮的右半部分：\(L_i = R_{i-1}\)
    - 新右半部分 = 上一轮左半部分 异或 轮函数输出：\(R_i = L_{i-1} \oplus f_i(R_{i-1})\)
    - 轮函数 \(f_i\) 输入32位，输出32位，由第i轮密钥 \(k_i\) 控制，不需要是可逆函数
  - 逆变换（解密规则）
    - 解密时第i轮逆变换
    - 恢复上一轮右半部分 = 当前轮左半部分：\(R_{i-1} = L_i\)
    - 恢复上一轮左半部分 = 当前轮右半部分 异或 轮函数输出：\(L_{i-1} = R_i \oplus f_i(L_i)\)
- DES（数据加密标准）
  - 历史背景
    - 1970年代：德国密码学家Horst Feistel在IBM设计了Lucifer算法，密钥长度128位，分组长度128位
    - 1973年：美国国家标准局(NBS)公开征集分组密码标准，IBM提交Lucifer的改进版本，即DES
    - 1976年：DES正式成为美国联邦标准，最终参数：密钥长度56位，分组长度64位（FIPS-46-3标准）
    - 1997年：DES被穷举搜索破解，56位密钥长度过短，无法抵抗现代计算能力
    - 2000年：NIST正式选定AES替代DES作为新标准
  - 历史意义
    - 是第一个全球通用的工业级分组密码标准，使用长达20余年
    - 除密钥长度过短外，本身结构极其安全，至今没有比穷举搜索更有效的实用攻击
  - DES加密整体流程
    - 初始置换IP：64位明文输入，按固定规则重排比特顺序，输出分为左32位\(L_0\)、右32位\(R_0\)
    - 16轮Feistel迭代：每轮使用一个48位的轮密钥\(k_i\)，执行Feistel变换
    - 左右交换SW：16轮结束后，将左右两半交换位置
    - 逆初始置换\(IP^{-1}\)：按IP的逆规则重排比特，输出最终64位密文
    - 密钥调度：56位主密钥生成16个48位的轮密钥
  - 初始置换IP与逆置换\(IP^{-1}\)
    - 初始置换IP规则
      - 输入64位比特 \(x = x_1x_2x_3\cdots x_{64}\)，输出64位 \(y = y_1y_2\cdots y_{64}\)
      - \(y_1 = x_{58}\)，\(y_2 = x_{50}\)，\(y_3 = x_{42}\)，\(y_4 = x_{34}\)，\(y_5 = x_{26}\)，\(y_6 = x_{18}\)，\(y_7 = x_{10}\)，\(y_8 = x_{2}\)，\(\cdots y_{64} = x_7\)
    - 逆初始置换\(IP^{-1}\)规则
      - 输入64位 \(y = y_1y_2\cdots y_{64}\)，恢复原始输入 \(x = x_1x_2\cdots x_{64}\)
      - \(x_1 = y_{40}\)，\(x_2 = y_8\)，\(x_3 = y_{48}\)，\(x_4 = y_{16}\)，\(x_5 = y_{56}\)，\(x_6 = y_{24}\)，\(x_7 = y_{64}\)，\(x_8 = y_{32}\)，\(\cdots x_{64} = y_{25}\)
    - 注意：初始置换和逆置换没有密码学安全作用，仅为硬件实现优化设计
  - 密钥调度算法（生成16个轮密钥）
    - PC1置换
      - 输入64位主密钥（其中8位是奇偶校验位，实际有效密钥56位）
      - 按PC1表筛选掉校验位，输出56位有效密钥，拆分为左28位、右28位两个部分
    - 循环左移
      - 第1、2、9、16轮：左右两半各自循环左移1位
      - 其余所有轮：左右两半各自循环左移2位
    - PC2置换
      - 移位后的56位左右两半合并，按PC2表筛选输出48位，作为当前轮的轮密钥\(k_i\)
    - PC1置换表
      - 左半部分28位：57,49,41,33,25,17,9；1,58,50,42,34,26,18；10,2,59,51,43,35,27；19,11,3,60,52,44,36
      - 右半部分28位：63,55,47,39,31,23,15；7,62,54,46,38,30,22；14,6,61,53,45,37,29；21,13,5,28,20,12,4
    - PC2置换表
      - 14,17,11,24,1,5,3,28；15,6,21,10,23,19,12,4；26,8,16,7,27,20,13,2；41,52,31,37,47,55,30,40；51,45,33,48,44,49,39,56；34,53,46,42,50,36,29,32
  - DES轮函数（Mangler函数）
    - 输入：32位右半部分\(R_{i-1}\)、48位轮密钥\(k_i\)，输出32位结果
    - 扩展置换E：将32位输入扩展为48位，目的是和48位轮密钥异或，同时增加扩散性
    - 密钥异或：扩展后的48位和48位轮密钥按位异或
    - S盒代换：48位拆分为8个6位分组，每个6位输入送入对应的S盒，输出4位，8个S盒共输出32位
      - 每个S盒是6位输入→4位输出的非线性映射，不可逆（4对1映射）
      - 输入规则：6位输入\(a_5a_4a_3a_2a_1a_0\)，行号由首尾两位\(a_5a_0\)决定，列号由中间四位\(a_4a_3a_2a_1\)决定
      - 每一行包含所有4位可能的输出值，避免输出偏差
      - 雪崩效应：输入改变1位，输出至少改变2位，保证明文差异快速扩散
    - P置换：32位输出按固定规则重排，得到最终32位轮函数输出
      - 混合置换设计：每个S盒的输出会影响下一轮的6个S盒，保证全轮扩散
- DES解密
  - 解密核心规则

- AES
  - 抽象代数基础  
    - 整除性
      - 定义：设\(\mathbb{Z}\)为整数集。设\(a, b \in \mathbb{Z}\)且\(a ≠0\)
      - a整除b：存在\(c \in \mathbb{Z}\)使得\(b=a c\)
      - a是b的约数；b是a的倍数
      - \(a|b ; a \nmid b\)
      - \(n \in{2,3, ...}\)为素数，当且仅当n的正约数只有1和n
      - 若\(n \in{2,3, ...}\)不是素数，则称为合数
      - 定理(算术基本定理)：每个大于1的整数n可唯一表示为\(n=p_{1}^{e_{1}} \cdots p_{r}^{e_{r}}\)，其中\(p_{1}, ..., p_{r}\)为不同素数，\(p_{1}<\cdots<p_{r}\)且\(e_{1}, ..., e_{r} ≥1\)
      - 定理(带余除法)：设\(a, b \in \mathbb{Z}\)且\(b>0\)。则存在唯一整数q, r使得\(0 ≤r<b\)且\(a=b q+r\)
      - a mod b定义为r
    - 最大公约数
      - 定义：设\(a, b \in \mathbb{Z}\)且\({a, b} \neq{0}\)
      - 公约数：整数d满足\(d|a, d| b\)
      - 最大公约数gcd\((a, b)\)：a和b的最大公约数
      - 例子：\(a=12=2^{2} 3^{1}\) \(b=18=2^{1} 3^{2}\) \(gcd(a, b)=2^{1} 3^{1}=6\)
      - 互素：\(gcd(a, b)=1\)
      - 定理：存在整数s, t使得gcd\((a, b)=a s+b t\)
      - 扩展欧几里得算法：\(EEA(a, b)=(gcd(a, b), s, t)\)
      - 定理
        - 若\(a, b, c \in \mathbb{Z}\)，\(c | a b\)且gcd\((a, c)=1\)，则\(c | b\)
        - 若p为素数且\(p | a b\)，则\(p | a\)或\(p | b\)
        - 若\(a|N, b| N\)且gcd\((a, b)=1\)，则\(a b | N\)
    - 同余
      - 定义：设\(n \in \mathbb{Z}^{+}\)。若\(n |(a-b)\)，记为\(a \equiv b\) (mod n)
      - \(a \equiv b\) (mod n)称为同余式；n称为模；a模n同余于b
      - 定理：设\(n \in \mathbb{Z}^{+}\)。对任意\(a \in \mathbb{Z}\)，存在唯一整数r使得\(0 ≤r<n\)且\(a \equiv r\) (mod n)
      - 定义：设\(a \in \mathbb{Z}\)，\(n \in \mathbb{Z}^{+}\)。\([a]_{n}=a+n \mathbb{Z}={a+n x: x \in \mathbb{Z}}\)称为a模n的剩余类
      - 定义：设n>0为整数。\(\mathbb{Z}_{n}={[0]_{n},[1]_{n}, ...,[n-1]_{n}}\)定义为模n的所有剩余类集合
      - \(\mathbb {Z}_{n}=\{ 0,1,... ,n-1\}\)
    - 剩余类
      - 定义：设\(n \in \mathbb{Z}^{+}\)且\(\mathbb{Z}_{n}={[0]_{n},[1]_{n}, ...,[n-1]_{n}}\)。定义
      - 加法：\([a]_{n}+[b]_{n}=[a+b]_{n}\)
      - 减法：\([a]_{n}-[b]_{n}=[a-b]_{n}\)
      - 乘法：\([a]_{n} \cdot[b]_{n}=[a \cdot b]_{n}\)
      - 定义：设\(n \in \mathbb{Z}^{+}\)且\([a]_{n} \in \mathbb{Z}_{n}\)。\([s]_{n} \in \mathbb{Z}_{n}\)称为\([a]_{n}\)的逆元，若\([a]_{n}[s]_{n}=[1]_{n}\)
      - 除法：若\([a]_{n}[s]_{n}=[1]_{n}\)，定义\(\frac{[b]_{n}}{[a]_{n}}=[b]_{n} \cdot[s]_{n}\)
      - 定理：设\(n \in \mathbb{Z}^{+}\)。\([a]_{n} \in \mathbb{Z}_{n}\)有逆元当且仅当gcd\((a, n)=1\)
      - \(\mathbb{Z}_{6}={0,1,2,3,4,5}\)
      - 1,5有逆元：\(1 \cdot 1=1\)；\(5 \cdot 5=1\)
      - 定义：设\(n \in \mathbb{Z}^{+}\)。定义\(\mathbb{Z}_{n}^{*}={[a]_{n} \in \mathbb{Z}_{n}}\)：gcd(a, n)=1
      - \(\mathbb{Z}_{5}^{*}=\{1,2,3,4\} ; \mathbb{Z}_{6}^{*}=\{1,5\}\)
    - 群
      - 定义：集合G和G上的二元运算*构成群，若满足
      - 封闭性：\(\forall a, b \in G\)，\(a * b \in G\)
      - 结合律：\(\forall a, b, c \in G\)，\(a *(b * c)=(a * b) * c\)
      - 单位元：\(\exists e \in G\)，\(\forall a \in G\)，\(a * e=e * a=a\)
      - 逆元：\(\forall a \in G\)，\(\exists b \in G\)使得\(a * b=b * a=e\)
      - 定义：群\((G, *)\)称为阿贝尔群，若满足
      - 交换律：\(\forall a, b \in G\)，\(a * b=b * a\)
      - 例子：\((\mathbb{Z}_{n},+)\)是阿贝尔群 //+为剩余类加法
      - 封闭性：\(\forall[a]_{n}, [b]_{n} \in \mathbb{Z}_{n}\)，\([a]_{n}+[b]_{n}=[a+b]_{n} \in \mathbb{Z}_{n}\)
      - 结合律：\(\forall[a]_{n}, [b]_{n}, [c]_{n} \in \mathbb{Z}_{n}\)，\([a]_{n}+([b]_{n}+[c]_{n})=[a+b+c]_{n}=([a]_{n}+[b]_{n})+[c]_{n}\)
      - 单位元：\(\exists[0]_{n} \in \mathbb{Z}_{n}\)，\(\forall[a]_{n} \in \mathbb{Z}_{n}\)，\([a]_{n}+[0]_{n}=[0]_{n}+[a]_{n}=[a]_{n}\)
      - 逆元：\(\forall[a]_{n} \in \mathbb{Z}_{n}\)，\(\exists[-a]_{n} \in \mathbb{Z}_{n}\)使得\([a]_{n}+[-a]_{n}=[-a]_{n}+[a]_{n}=[0]_{n}\)
      - 交换律：\(\forall[a]_{n}, [b]_{n} \in \mathbb{Z}_{n}\)，\([a]_{n}+[b]_{n}=[a+b]_{n}=[b+a]_{n}=[b]_{n}+[a]_{n}\)
      - 例子：\((\mathbb{Z}_{n}^{*}, \cdot)\)是阿贝尔群 //⋅为剩余类乘法
      - 封闭性：\(\forall[a]_{n}, [b]_{n} \in \mathbb{Z}_{n}^{*}\)，\([a]_{n} \cdot[b]_{n}=[a b]_{n} \in \mathbb{Z}_{n}^{*}\)
      - 结合律：\(\forall[a]_{n}, [b]_{n}, [c]_{n} \in \mathbb{Z}_{n}^{*}\)，\([a]_{n} \cdot ([b]_{n} \cdot [c]_{n})=[a b c]_{n}=([a]_{n} \cdot [b]_{n}) \cdot [c]_{n}\)
      - 单位元：\(\exists[1]_{n} \in \mathbb{Z}_{n}^{*}\)，\(\forall[a]_{n} \in \mathbb{Z}_{n}^{*}\)，\([a]_{n} \cdot [1]_{n}=[1]_{n} \cdot [a]_{n}=[a]_{n}\)
      - 逆元：\(\forall[a]_{n} \in \mathbb{Z}_{n}^{*}\)，\(\exists[s]_{n} \in \mathbb{Z}_{n}^{*}\)使得\([a]_{n} \cdot [s]_{n}=[s]_{n} \cdot [a]_{n}=[1]_{n}\)
      - 交换律：\(\forall[a]_{n}, [b]_{n} \in \mathbb{Z}_{n}^{*}\)，\([a]_{n} \cdot [b]_{n}=[a b]_{n}=[b a]_{n}=[b]_{n} \cdot [a]_{n}\)
      - 加法阿贝尔群：\((G,+)\)
      - 单位元：0；逆元：\(-a\)
      - \(\sum_{i=1}^{k} \alpha_{i}=\alpha_{1}+\alpha_{2}+\cdots+\alpha_{k} ; k \alpha=\alpha+\alpha+\cdots+\alpha\)
      - 乘法阿贝尔群：\((G, \cdot)\)
      - 单位元：1；逆元：\(a^{-1}\)
      - \(\prod_{i=1}^{k} \alpha_{i}=\alpha_{1} \cdot \alpha_{2} \cdot \cdots \cdot \alpha_{k} ; \alpha^{k}=\alpha \cdot \alpha \cdot \cdots \cdot \alpha\)
    - 有限域
      - 定义：有限域是有限集合𝔽及两个二元运算+、⋅，满足以下条件
      - \((\mathbb{F},+)\)是阿贝尔群
      - (𝔽∖{0}, ⋅)是阿贝尔群
      - 分配律：对所有\(a, b, c \in \mathbb{F}\)，\(a \cdot(b+c)=a b+a c\)
      - 例子：设p为素数。则\((\mathbb{Z}_{p},+, \cdot)\)是有限域
      - +为模p剩余类加法
      - ⋅为模p剩余类乘法
      - 备注：\((\mathbb{R},+, \cdot)\)也是域，但不是有限域
      - 定理：有限域总有\(p^{k}\)个元素，其中p为素数，k>0为整数；反之，对任意素数p和整数k>0，存在\(p^{k}\)个元素的有限域
      - 例子：\(\mathbb{Z}_{2}[X]=\left\{a_{0}+a_{1} X+\cdots+a_{d} X^{d}: d=0,1, ... ; a_{i} \in \mathbb{Z}_{2}\right\}\)
      - 加法：\(\sum_{i=0}^{d} a_{i} X^{i}+\sum_{i=0}^{d} b_{i} X^{i}=\sum_{i=0}^{d}\left(a_{i}+b_{i}\right) X^{i}\)
      - 乘法：\(\sum_{i=0}^{d} a_{i} X^{i} \cdot \sum_{i=0}^{d} b_{i} X^{i}=\sum_{i=0}^{2 d}\left(\sum_{j=0}^{i} a_{j} b_{i-j}\right) X^{i}\)
      - 系数模2
      - 例子：设\(\mathbb{F}_{2^{2}}=\mathbb{Z}_{2}[X] /\left(X^{2}+X+1\right)=\{0,1, X, 1+X\}\)
      - \(( a _ { 0 } + a _ { 1 } X ) + ( b _ { 0 } + b _ { 1 } X ) = ( a _ { 0 } + b _ { 0 } ) + ( a _ { 1 } + b _ { 1 } ) X\)
      - \((a_{0}+a_{1}X)\cdot (b_{0}+b_{1}X) = a_{0}b_{0}+(a_{0}b_{1}+a_{1}b_{0})X+a_{1}b_{1}X^{2} = a_{0}b_{0}+(a_{0}b_{1}+a_{1}b_{0})X+a_{1}b_{1}(X+1) = a_{0}b_{0}+a_{1}b_{1}+(a_{0}b_{1}+a_{1}b_{0}+a_{1}b_{1})X\)
      - \(X^{2}+X+1\)的倍数替换为0
      - 系数模2
      - 则\((\mathbb{F}_{2^{2}},+, \cdot)\)是有限域
