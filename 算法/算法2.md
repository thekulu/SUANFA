### NP 与计算不可解性

- 问题分类
  - 根据是否具有多项式时间算法，分类问题。（实际上，多项式时间算法能够处理规模巨大的问题）

    | Yes                      |Solution              | Probably no     |
    | --------------------------- | --------------------------- |--------------- |
    | Shortest path               |DP| Longest path    |
    | Bipartite Matching                    |Max Flow| 3D-matching     |
    | Min cut                     |Max Flow| Max cut         |
    | 2-SAT                       |强连通分量| 3-SAT           |
    | Planar 4-color              |四色定理| Planar 3-color  |
    | Bipartite vertex cover      |等价于Bipartite Matching| Vertex cover    |
    | Primality testing (2002)    |AKS| Factoring       |

    - 被证明需要指数时间的问题：（EXPTIME-complete）
      - k步停机问题：给定一个大小为 log k 的程序，它是否最多在 k 步内终止？
      - 在 n×n 格的跳棋，国象等广义博弈游戏中，给定一个棋盘局面，黑方能否保证获胜？
    - 大量基础问题始终无法被分类
    - 有必要证明这些基础问题在“计算上等价”，且是同一个极其困难问题的不同表现形式。
- 多项式归约
  - 若问题 X 的任意实例均可通过以下方式求解，则问题 X 可多项式归约为问题 Y：
    - 执行多项式数量的标准计算步骤
    - 向能求解问题 Y 的预言机发出多项式数量的调用
    - 由于记录发送到预言机的实例需要花费时间， y 的实例必须是多项式大小的
  - 记作 $$X ≤_{p} Y$$
  - 性质：
    - 设计算法。若 X ≤p y 且 y 可在多项式时间内求解，则 X 也可在多项式时间内求解；
    - 证明不可解性。若 X ≤p y 且 X 无法在多项式时间内求解，则 y 无法在多项式时间内求解；
    - 证明等价性。若 X ≤p y 且 y ≤p X，则记作 X ≡p y。此时，X 能否在多项式时间内求解，当且仅当 y 能否在多项式时间内求解
  - 归约策略：
    - 基于简单等价关系的归约
      - 顶点覆盖 ≡p 独立集
        - 顶点覆盖：给定一个图 G = (V, E) 和一个整数 k，是否存在一个顶点子集 S ⊆ V，使得 |S| ≤ k，且对于每条边，其至少有一个端点属于 S
        - 独立集：给定一个图 G = (V, E) 和一个整数 k，是否存在一个顶点子集 S ⊆ V，使得|S| ≥ k，且对于每条边，其两端点中至多有一个属于 S
        - 证明：
          - 对于顶点覆盖，若找到 S，则 E 的 每条边至少有1个顶点属于 S，则对于V - S，E 的 每条边至多有1个顶点属于 V - S，V - S是 V的独立集；反之同理。两问题等价
    - 从特例归约到一般情况
      - 顶点覆盖 ≤p 集合覆盖
        - 集合覆盖。给定一个元素集 U、U 的子集集合 S1, S2, …, Sm 以及一个整数 k，是否存在一族 个数≤ k 的上述集合，其并集等于 U？
          - 应用： 有 m 个可用软件，设 U 为系统应具备的 n 种能力，第 i 个软件提供能力集 Si ⊆ U，能否使用最少的软件数量实现全部 n 种能力
        - 证明：
          - 令 U = E, Si = {e:vi ∈ e}，1 ≤ i ≤ |V|,则若能找到集合覆盖，意味着k个顶点覆盖了E，即可找到顶点覆盖S={vi：i满足Si属于集合覆盖}
    - 利用小工具编码进行归约
      - 3-SAT ≤p 独立集
        - SAT
          - literal：布尔变量或其否定形式 $x_i$ or $\overline{x_i}$
          - clause：literal的析取式 \[
C_j = x_1 \lor \overline{x_2} \lor x_3
\]
          - 合取范式：命题公式 𝝫，它是clause的合取式 \[
\Phi = C_1 \land C_2 \land C_3 \land C_4
\]
          - 给定合取范式 𝝫，是否存在一个使其成立的真值赋值？
          - 3-SAT：每个clause恰好包含 3 个literal的 SAT 问题
            - Ex: \[
                \left(\overline{x_1} \lor x_2 \lor x_3\right)
                \land
                \left(x_1 \lor \overline{x_2} \lor x_3\right)
                \land
                \left(\overline{x_1} \lor x_2 \lor x_4\right)
                \]

                Yes: $x_1 = \text{true},\ x_2 = \text{true},\ x_3 = \text{false},\ x_4 = \text{false}.$
        - 编码：
          - G 包含每个clause的 3 个顶点，每个literal对应一个顶点;
          - 将clause中的 3 个literal以三角形的方式连接起来;
          - 将literal与其否定形式连接
          - 若赋值为真/假，则选取/不选取对应顶点
           ![alt text](2image.png)
        - G 包含一个大小为 k = |𝝫| 的独立集当且仅当 𝝫 是可满足的
          - =>
            - 设 S 是一个大小为 k 的独立集；
            - S 必须在每个三角形中恰好包含一个顶点；
            - 将这些literal赋真 ，并将其他变量以一致的方式赋值；
            - 真值赋值是一致的，且所有clause均被满足；
          - <=
            - 给定一个满足条件的赋值，从每个三角形中选取一个真literal，这便是一个大小为 k 的独立集。
        - 事实上，证明了3-SAT ≤p 1 in 3-SAT ≤p独立集(这说明**归约的构造过程可以增强X的命题强度**)

- NP
  - 决定性问题
    - X 是一个字符串集合
    - Instance：字符串 s
    - 算法 A 解决问题 X：A(s) = yes 当且仅当 s ∈ X
  - P的定义:若对于任意字符串 s，A(s) 最多在 p(|s|) 步内终止，则算法 A 在多项式时间内运行，X是P问题，其中 p(∙) 是一个多项式。
    - Ex:
      - 质数集：X = {2, 3, 5, 7, 11, 13, 17, 23, 29, 31, 37, …}
      - Instance：s = 592335744548702854681(|s| =logn,n为数字大小)
      - 算法：[Agrawal-Kayal-Saxena, 2002] $$p(|s|) = \log^{8}(n) = |s|^{8}$$

  - 验证算法
    - 验证者从“管理”角度看待问题
    - 验证者本身并不判定 s ∊ X；而是检查一个声称 s ∊ X 的证明 t 是否正确
    - 如果对于任意字符串 s，当且仅当存在字符串 t 使得 C(s, t) = yes 时，s ∈ X，则算法 C(s, t) 是问题 X 的验证器。
  - NP(nondeterministic polynomial-time)的定义：若存在多项式时间验证器的决定性问题，即C(s, t) 是一个多项式时间算法，且对于某个多项式 p(∙)，满足 |t| <= p(|s|)，则X为NP问题
    - Ex:
      - COMPOSITES
        - X:给定一个整数 s，s 是合数吗？
        - 验证：s 的一个非平凡因数 t。注意，当且仅当 s 是合数，才存在这样的验证。此外，|t| <= |s|。
        - 验证器：

            ```pseudo
            boolean C(s, t) {
            if (t ≤ 1 or t ≥ s)
            return false
            else if (s is a multiple of t)
            return true
            else
            return false
            }
            ```

        - Instance:s = 437669
        - 验证:t = 541 或 809
        - 结论:合数问题 属于 NP
      - 3-SAT
        - X:给定一个 CNF 范式 𝛟，是否存在一个满足该范式的赋值？
        - 验证：为 n 个literal赋予真值
        - 验证器：检查𝛟中的每个clause是否至少包含一个真literal
        - instance $s$ \[
        \left(\overline{x_1} \lor x_2 \lor x_3\right)
        \land
        \left(x_1 \lor \overline{x_2} \lor x_3\right)
        \land
        \left(x_1 \lor x_2 \lor x_4\right)
        \land
        \left(\overline{x_1} \lor \overline{x_3} \lor \overline{x_4}\right)
        \]
        - certificate $t$
        \[
        x_1 = 1,\ x_2 = 1,\ x_3 = 0,\ x_4 = 1
        \]
        - 结论:3-SAT 属于 NP
      - HAM-CYCLE
        - X:对于给定的无向图 G = (V, E)，是否存在一个简单环 C，使得它经过每个顶点？
        - 验证：n 个顶点的置换
        - 验证器：检查该置换是否包含 V 中的每个节点且仅包含一次，并且排列中每对相邻节点之间都存在一条边
        ![alt text](2image-1.png)
        - 结论:HAM-CYCLE 属于 NP

  - P,EXP,NP
    - P. 存在多项式时间算法的判定问题
    - EXP. 存在指数时间算法的判定问题
    - NP. 存在多项式时间验证器的判定问题
    - P ⊆ NP
      - 设 X 是 P 中的任意问题,根据定义，存在一个多项式时间算法 A(s) 能解决问题 X。令 t = ℇ（空串），验证器 C(s, t) = A(s)
    - NP ⊆ EXP
      - 考虑任意一个属于 NP 的问题 X，根据定义，存在一个针对 X 的多项式时间验证器 C(s, t)，要解决输入 s，对所有满足 |t| <= p(|s|) 的字符串 t 运行 C(s, t)，如果 C(s, t) 对其中任何一个返回“是”，则返回“是”，算法时间为$$O(|Σ|^{p(|s|)})$$,Σ为字母表
  - P =? NP[Cook 1971, Edmonds, Levin, Yablonski, Godel]
    - 千禧年七大难题之一 
    - 决定性问题真的像验证那样简单吗？如果是，则存在3-COLOR、TSP、SAT、FACTOR(将破坏RSA加密技术,并可能导致经济崩溃) 等问题的有效算法；如果不是，3-COLOR、TSP、SAT 等问题不存在有效算法。
  - NP-Completeness
    - 多项式归约：
      - 若问题 X 的任意实例均可通过以下方式求解，则问题 X 可多项式归约为问题 Y：
        - 执行多项式数量的标准计算步骤
        - 向能求解问题 Y 的预言机发出多项式数量的调用
        - 由于记录发送到预言机的实例需要花费时间， y 的实例必须是多项式大小的
    - 多项式变换：
      - 若给定任意输入 x 到问题 X，我们能在多项式时间内构造出一个输入 y，使得 x 是 X 的“是”实例当且仅当 y 是 Y 的“是”实例，则问题 X 通过多项式变换（Karp）映射到问题 Y。
    - 多项式变换是一种多项式归约算法，它仅需对 Y 进行一次调用，且该调用恰好发生在 X 的算法结束时。几乎所有先前的归约算法都采用这种形式。那么，多项式变换是否真包含于多项式归约呢？
    - 开放性问题：多项式归约与多项式变换是等价的概念吗？或者说，能否找到一个问题，在多项式归约下为NPC,而多项式变换下不是NPC？
    - NP-Complete：NP类中的一个问题Y，具有如下性质：对于NP类中的任意问题X，X ≤p Y
      - 假设 Y 是一个 NP-Complete。那么，Y 能在多项式时间内求解当且仅当 P = NP。
        - <= 若 P = NP， Y 属于 NP ,则 Y 可在多项式时间内求解。
        - => 假设 Y 可在多项式时间内求解。设 X 为 NP 类中的任意问题。由于 X ≤ P，因此我们可在多项式时间内求解 X, NP ⊆ P。已知 P ⊆ NP,因此 P = NP
      - “首个”NP-Complete
        - CIRCUIT-SAT。给定一个由与门、或门和非门构成的组合逻辑电路，是否存在某种方式来设置该电路的输入，使得其输出为1？
          ![alt text](2image-2.png)
        - CIRCUIT-SAT 是 NP-complete. [Cook 1971, Levin 1973]
          - CIRCUIT-SAT是NP
          - 简略的证明：
            - 任何以固定输入长度 n 作为输入并输出“是”或“否”的算法，都可以用这样的电路来表示。此外，如果算法的运行时间是多项式级的，那么该电路的规模也是多项式级的。
              - 证明中的简略部分；固定输入长度很重要，这反映了**算法（图灵机，输入可变长）与电路（输入定长）之间的基本区别**，而在此情况下算法如何用电路表示原论文中有详细内容，在此省略。 
            - 考虑NP类中的某个问题X。该问题有一个多项式验证器C(s, t)。要判断s是否属于X，需要知道是否存在长度为p(|s|)的验证t，使得C(s, t) = yes
            - 将 C(s, t) 视为一个作用于 |s| + p(|s|) 位（输入 s，验证 t）的算法，并将其转换为一个多项式大小的电路 K：
              - 前 |s| 位硬编码为 s
              - 剩余的 p(|s|) 位表示 t，值未知
            - 电路 K 可满足当且仅当存在 t 使得 C(s, t) = yes

          - 3-SAT 是 NP-Complete
            - CIRCUIT-SAT ≤p 3-SAT
              - 3-SAT 属于 NP 
              - 设 K 为任意电路。
                  ![alt text](2image-4.png)
              - 为电路的每个元素 i 创建一个 3-SAT 变量 xi；
              - 使电路在每个节点计算出正确的值：
                  - X2 = ¬ X3，构造$x_2 \lor x_3,\ \overline{x_2} \lor \overline{x_3}$
                  - X1 = X4 ∨ X5，构造$x_1 \lor \overline{x_4},\ x_1 \lor \overline{x_5},\ \overline{x_1} \lor x_4 \lor x_5$
                  - X0 = X1 ∧ X2，构造$\overline{x_0} \lor x_1,\ \overline{x_0} \lor x_2,\ x_0 \lor \overline{x_1} \lor \overline{x_2}$
              - 硬编码输入值和输出值
                  - X5 = 0，构造$\overline{x_5}$
                  - X0 = 1，构造$x_0$
              - 将长度小于 3 的clause转换为长度恰好为 3 的clause
              - \(\Phi =
                  \begin{aligned}
                  & (x_2 \lor x_3 \lor z) \land (\overline{x_2} \lor \overline{x_3} \lor z) \\
                  \land\ & (x_1 \lor \overline{x_4} \lor z) \land (x_1 \lor \overline{x_5} \lor z) \land (\overline{x_1} \lor x_4 \lor x_5) \\
                  \land\ & (\overline{x_0} \lor x_1 \lor z) \land (\overline{x_0} \lor x_2 \lor z) \land (x_0 \lor \overline{x_1} \lor \overline{x_2}) \\
                  \land\ & (\overline{x_5} \lor z \lor z) \land (x_0 \lor z \lor z)
                  \end{aligned}\)
              - 𝛟 可满足当且仅当 K 的输入可以设置为 s，使其输出为 1 
                - <=
                  - 假设存在满足某些输入的 K，使得其输出为 1
                  - 计算 K 中所有节点的值
                  - 根据构造，这组值满足 𝛟
                - =>
                  - 假设 𝛟 是可满足的
                  - 𝛟 的变量赋值确定了 K 中所有节点的值
                  - 构造确保了 K 中所有节点都被正确计算，且输出为1
          - HAM-CYCLE是NPC
            - HAM-CYCLE：给定一个无向图 G = (V, E)，是否存在一个单环，其中包含 V 中的每个顶点？
            - DIR-HAM-CYCLE：给定有向图 G = (V, E)，是否存在一个包含 V 中所有节点的单向有向环？
            - 3-SAT ≤p DIR-HAM-CYCLE
              - DIR-HAM-CYCLE是NP
              - 给定一个包含 n 个变量 xi 和 k 个clause的 3-SAT instance 𝞍，构造一个具有 $2^{n}$ 个哈密尔顿环的图 G
              - 直观解释：沿路径 i 从左向右遍历，并将变量 xi 设为 1
              - 对于每个clause，添加一个节点和 6 条边
              - ![alt text](2image-6.png)
              - 𝞍 可满足当且仅当 G 存在一个哈密顿回路
                - =>
                  - 假设 3-SAT 实例有一个满足的赋值 x*：
                  - 在 G 中定义汉密尔顿环如下：
                    - 若 x*i = 1，则从左向右遍历第 i 行;
                    - 若 x*i = 0，则从右向左遍历第 i 行;
                    - 对于每个clause Cj，至少存在一行 i可以将节点 Cj 接入环路 
                - <=
                  - 假设 G 包含一个哈密顿环 T
                  - 如果环 T 进入clause节点 Cj，它必须通过配对边离开该节点
                  - 因此，Cj 节点的前后相邻节点在 G 中由边 e 连接起来
                  - 将 Cj 从环中移除，并用边 e 替换它，即可得到 G – { Cj } 上的哈密顿环
                  - 以此类推，最终得到 G – { C1, C2, …, Ck} 上的哈密尔顿环 T’
                  - 若 T’ 从左至右遍历第 i 行，则设 x*i = 1
                  - 由于 T 访问了每个clause节点 Cj，每个clause均被满足    
            - DIR-HAM-CYCLE ≤p HAM-CYCLE
              - HAM-CYCLE是NP
              - 给定一个有向图 G = (V, E)，构造一个具有 3n 个节点的无向图 G’
              - ![alt text](2image-7.png)
              - G 具有哈密顿环当且仅当 G’ 具有哈密顿环
                - =>
                  - 假设图 G 存在一个有向哈密顿回路
                  - 那么图 G’ 存在一个无向哈密顿回路（顺序相同） 
                - <= 
                  - 假设 G’ 包含一个无向哈密尔顿环
                  - 该环必须按以下两种顺序之一访问 G’ 中的节点：
                  - …, B, G, R, B, G, R, B, G, R, B, …
                  - …, B, R, G, B, R, G, B, R, G, B, …
                  - 该环中的蓝色节点在 G 中构成有向哈密尔顿环，或其逆环
              - 3-SAT ≤p HAM-CYCLE，3-SAT为NPC,HAM-CYCLE为NPC

  - Co-NP 与 NP 的非对称性
    - NP的不对称性：NP是存在多项式时间验证器的决定性问题。我们只需对“是”的实例给出简短的验证，而对于“否”的实例可能难以给出验证
      - Ex:
        - 可满足性（SAT）与重言式（TAUTOLOGY）
          - 可以通过给出赋值来验证一个 CNF 是可满足的
          - 如何验证一个CNF不可满足？
          - 重言式属于哪类问题？
            - SAT 是 NPC问题，且 SAT ≡p TAUTOLOGY
            - 但目前甚至不知道重言式是否属于 NP（TAUTOLOGY不满足NPC的第一个条件）
        - 哈密尔顿环与非哈密尔顿环
          - 可以通过给出一个哈密尔顿环来验证一个图是哈密尔顿图
          - 如何验证一个图不是哈密尔顿图？ 
    - Co-NP
      - 对于给定的决定性问题X，其补问题$\overline{X}$是指X的“是”和“否”的答案被互换，其余不变的对称问题。
      - Ex 
        - $\overline{X}$ = {0, 1, 4, 6, 8, 9, 10, 12, 14, 15, …}
          X = {2, 3, 5, 7, 11, 13, 17, 23, 29, …}
      - Co-NP：NP决定性问题的补集。对于“否”实例，存在简洁的验证器
    - NP =? co-NP 
      - 所有“是”实例存在简洁的验证器等价于所有“否”实例存在简洁的验证器吗？
    - 若 NP ≠ co-NP，则 P ≠ NP
      - P 具有补集封闭性，若 P = NP，则 NP 具有补集封闭性，NP = co-NP
    - [Edmonds 1965] NP ⋂ co-NP
      - 如果问题 X 同时属于 NP 和 co-NP，那么对于“是”与“否”的实例，都存在简洁的验证
      - Ex
        - 给定一个二分图，是否存在一个完美配对？
        - 若存在，能否给出一个完美配对？
        - 若不存在，能否给出一个节点集 S，使得 |N(S)| < |S|
    - P ⊆ NP ⋂ co-NP
    - P =? NP ⋂ co-NP
      - 许多属于NP ⋂ co-NP的问题最初被认为非平凡，直到数年后
      才被发现属于 P
      - 线性规划 [Khachiyan, 1979]
      - 素数判定 [Agrawal-Kayal-Saxena, 2002]
      - 因式分解问题属于NP⋂co-NP，但尚未确定是否属于P。如果存在多项式时间因式分解算法，RSA密码系统不再理论安全

### PSPACE
- PSPACE
  - 地理游戏。艾米说出她所在国家的首都c。鲍勃说出一个以c结尾的字母开头的首都c’。艾米和鲍勃重复这个游戏，直到其中一名玩家无法继续。艾米是否必然获胜？
    - Ex：Budapest → Tokyo → Ottawa → Ankara → Amsterdam → Moscow → Washington → Nairobi → …（布达佩斯 → 东京 → 渥太华 → 安卡拉 → 阿姆斯特丹 → 莫斯科 → 华盛顿 → 内罗毕 → …）
    - 图论中的地理游戏。给定一个有向图 G = (V, E) 和一个起始节点 s，两名玩家轮流进行，在可能的情况下，沿当前节点的一条边前往一个未访问过的节点。第一位玩家能否保证能做出最后一步合法移动？
    - 某些问题（尤其是涉及双人游戏和人工智能的问题）无法根据 P、NP 和 NPC进行分类
  - PSPACE：可在多项式空间内求解的决定性问题
    - P ⊆ PSPACE：多项式时间算法最多只能消耗多项式空间
      - 多项式时间算法的运行步数是 \(O(n^k)\)，k 为常数；
      - 算法每一步最多只新开 / 占用常数大小的内存空间；
      - 总占用空间 ≤ 总运行步数 ⇒ 空间也是 \(O(n^k)\)，即多项式空间。 
    - 3-SAT 属于 PSPACE 
      - 变量总共有 \(2^n\) 种布尔赋值组合；
      - 递归枚举所有赋值：
        - 依次给每个变量赋 0/1
        - 递归栈深度最多 n
      - 每枚举一个赋值，检查所有子句是否全部满足；
      - 找到满足赋值则输出 Yes，全部遍历完无满足赋值输出 No。
    - NP ⊆ PSPACE
      - 考虑NP中的任意问题Y
      - 由于Y ≤p 3-SAT，存在一种算法，能在多项式时间内解决Y，并调用3-SAT预言机多项式次
      - 该预言机可在多项式空间内实现
    - QSAT（Quantified 3-SAT，带量词的3-SAT）:设 𝚽(X1,…Xn) 是一个布尔CNF范式。下列命题范式是否为真？
      - $\exists x_1\ \forall x_2\ \exists x_3\ \forall x_4\ \cdots\ \forall x_{n-1}\ \exists x_n\ \Phi(x_1, \dots, x_n)$（假定n为奇数）
      - Ex：艾米先为 X1 选定真值，然后由鲍勃为 X2 选定，接着由艾米为 X3 选定，依此类推。无论鲍勃如何选择，艾米都能满足 𝚽 吗？ 
        -  $$
          (x_1 \lor x_2) \land (x_2 \lor \overline{x_3}) \land (x_1 \lor \overline{x_2} \lor x_3)
          $$
        - Yes
        -  Amy sets $x_1$ true; Bob sets $x_2$; Amy sets $x_3$ to be same as $x_2$.
        - $$
          (x_1 \lor x_2) \land (\overline{x_2} \lor \overline{x_3}) \land (\overline{x_1} \lor \overline{x_2} \lor x_3)
          $$
        - No
        - If Amy sets $x_1$ false; Bob sets $x_2$ false; Amy loses.
          If Amy sets $x_1$ true; Bob sets $x_2$ true; Amy loses.
      - QSAT ∈ PSPACE
        - 递归尝试所有可能的情况
          - 每个子问题只需一个比特
          - 空间消耗与函数调用栈的深度成正比，最多n

    - 规划问题
      - 8拼图、15拼图[Sam Loyd 1870s]
        - 棋盘：标有1至8的方块组成的3×3网格/标有1至15的方块组成的4×4网格
        - 合法走法：将相邻的方块滑入空白格中
        - 找出合法走法的序列，将初始布局转换为目标布局

        - 初始布局：子集 c0 ⊆ C 表示初始满足的集合
        - 目标布局：子集 c* ⊆ C 表示我们试图满足的集合
        - 操作：设 O = { O1, …, Ok }
          - 调用操作符 Oi 时，必须满足某些先决条件
          - 调用 Oi 之后，某些条件变为真，某些条件变为假

            - 执行 $O_i$ 后，条件 $C_{79}$ 和 $C_{98}$ 变为真
            - 执行 $O_i$ 后，条件 $C_{78}$ 和 $C_{99}$ 变为假

      - 布局图 G
        - 为每一种可能的布局创建一个节点，共 $2^n$ 个节点
        - 如果存在一个操作算子可以将布局 $c'$ 转换为布局 $c''$，则在图中添加一条从 $c'$ 指向 $c''$ 的边
      - 规划问题：在布局图中，是否存在一条从初始布局 $c_0$ 到目标布局 $c^*$ 的路径？
      - 规划问题属于 EXPTIME
        - 可以在布局图上BFS，寻找从 $c_0$ 到 $c^*$ 的路径（直接BFS的时间复杂度为O（V+E），空间复杂度为O(V)，目标比规划问题复杂，并不是最优算法）
      - 规划问题属于 PSPACE
        - 布局图最多可包含 $2^n$ 个节点，其最短路径的长度最多可达 $2^n - 1$
        - 假设存在一条从 c1 到 c2 的路径，其长度 ≤ L
        - 从 c1 到中点的路径以及从中点到 c2 的路径，各自的长度均 ≤ L/2
        - 枚举所有可能的中点
        - 递归深度 = $\log_2L=O(n)$
    - PSPACE-Complete：若满足以下两个条件，则问题 Y 为PSPACE-Complete：Y 属于 PSPACE，且对于 PSPACE 中的任意问题 X，X ≤p Y。                   
      - QSAT 是 PSPACE-complete[Stockmeyer-Meyer 1973]
      - PSPACE ⊆ EXPTIME
        - QSAT 为 PSPACE-complete，并且可用之前的算法在指数时间解答QSAT

### 复杂度类别
- ![alt text](image-24.png)
#### 1. Recognizable (可识别性，图灵机可计算性，递归可枚举语言)
- **定义**：存在图灵机可以**接受**该语言中的字符串，对非语言字符串可能无限循环
- **地位**：计算理论中**最广义**的语言类，包含所有其他复杂度类
- **核心**：图灵机可识别，但不一定可判定
- 停机问题的补集Unrecognizable

#### 2. Decidable (可判定性，递归语言)
- **定义**：存在图灵机对所有输入**必定停机**，并给出接受/拒绝结果
- **包含关系**：$\text{Decidable} \subsetneq \text{Recognizable}$
- **核心**：可判定 = 可识别 + 图灵机必然停机
- 对角线语言，停机问题是典型的Recognizable而Undecidable问题

#### 3. EXPSPACE
- **定义**：可在**指数级空间**内判定的问题类
- **包含关系**：$\text{EXPTIME} \subsetneq \text{EXPSPACE}$
- **核心**：空间复杂度最高的实用复杂度类之一

#### 4. EXPTIME
- **定义**：可在**指数级时间**内判定的问题类
- **典型问题**：五子棋、上海麻将连连看
- **包含关系**：$\text{PSPACE} \subsetneq \text{EXPTIME}$

#### 5. PSPACE = NPSPACE
- **核心定理**：**萨维奇定理 (Savitch's Theorem)**
  确定性多项式空间 = 非确定性多项式空间
- **定义**：可在**多项式空间**内解决的问题
- **典型问题**：QBF、黑白棋、六贯棋、推箱子、华容道
- **地位**：连接时间复杂度与空间复杂度的核心类

#### 6. NP 与 coNP
- **NP**：非确定性多项式时间，解可**多项式时间验证**
  典型问题：SAT、3-SAT
- **coNP**：NP 的补集，无解可多项式时间验证
  典型问题：重言式
- **关系**：$P \subseteq \text{NP} \cap \text{coNP}$

#### 7. P (确定性多项式时间)
- **定义**：可在**多项式时间**内求解的问题
- **地位**：计算机科学中“高效可解”的标准
- **包含关系**：$\text{CFL} \subsetneq \text{P}$

#### 8. CFL (上下文无关语言)
- **定义**：上下文无关文法生成、下推自动机识别
- **典型应用**：编程语言语法、括号匹配
- **包含关系**：$\text{Regular} \subsetneq \text{CFL}$

#### 9. Regular (正则语言)
- **定义**：有限自动机、正则表达式描述
- **地位**：**最受限**的语言类
- **典型应用**：词法分析、简单字符串匹配

#### 10. BPP (错误率有界概率多项式时间)
- **定义**：概率图灵机多项式时间判定，错误率有界
- **关系**：$P \subseteq \text{BPP} \subseteq \text{PSPACE}$

#### 已证明的包含关系
$$
\text{Regular} \subsetneq \text{CFL} \subsetneq \text{P} \subseteq \text{NP} \subseteq \text{PSPACE} \subsetneq \text{EXPTIME} \subsetneq \text{EXPSPACE} \subsetneq \text{Decidable} \subsetneq \text{Recognizable}
$$
#### 开放问题
1. $P \stackrel{?}{=} \text{NP}$
2. $\text{NP} \stackrel{?}{=} \text{coNP}$
3. $\text{BPP} \stackrel{?}{=} \text{P}$
